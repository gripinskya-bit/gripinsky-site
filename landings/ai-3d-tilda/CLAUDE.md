# Лендинг «ИИ в 3D» для Тильды

Как устроен проект и как его публиковать: README.md. Пробная публикация в Тильде: TILDA-TRIAL.md.

## Правила

- Источник правды: `src/`. Папка `dist/` генерируется командой `npm run build`, руками её не правим.
- Каждый CSS-селектор начинается с `.gai`. Правила для всей страницы пишутся как `html:has(.gai)` / `body:has(.gai)`. Имена `@keyframes` начинаются с `gai-`. Глобальные селекторы сломают разметку Тильды.
- Каждый блок в `src/index.html` лежит между `<!-- block:NN-name -->` и `<!-- /block -->` и обёрнут в `<div class="gai">`. Первым идёт `00-styles`.
- JS пишем внутри блока, которому он нужен, и ищем элементы внутри своей секции (`document.querySelector(".gai .pricing")`), а не по всему документу.
- После правок: `npm run build`, затем сверка `dist/tilda-preview.html` с `src/` на ширине 375 и 1440 px.

## Перед публикацией (перенесено из gripinsky-site/public/ai-3d/AGENTS.md)

13 октября 2026 года пользователь попросил напомнить: добавить UTM-метку к ссылкам на 1–2 уровень моделирования (https://gripinsky.ru/1-2lvl), то есть ко всем `a[data-modeling-course]`. Значения меток согласовать с пользователем, кампанию и метки самим не придумывать. Метки вписываются в `modelingCourseUtm` в `tilda.config.json`.

Новое обстоятельство: в Тильде лендинг будет на том же домене gripinsky.ru, что и страница 1–2 уровня. UTM на внутренних ссылках в Яндекс Метрике и GA4 перезаписывают источник визита, и исходная реклама теряется. Перед тем как вписывать метки, обсудить это с пользователем. Альтернатива: цель Метрики на клик по `a[data-modeling-course]`.
