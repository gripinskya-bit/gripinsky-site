# Лендинг «ИИ в 3D» · GRIPINSKY

Отдельный подпроект лендинга курса «От референса до доработанной 3D-модели — с помощью ИИ».
Задача: опубликовать его на текущем сайте gripinsky.ru (Тильда) до запуска нового сайта.

Лежит в репозитории сайта: `landings/ai-3d-tilda/`, в сборку сайта не входит (исключён в `tsconfig.json`). Исходник: папка `public/ai-3d/`, коммит `3d22e1a` от 17.10.2026.
Предпросмотр оригинала: https://gripinskya-bit.github.io/gripinsky-site/ai-3d/

## Что изменено относительно оригинала

- Все стили лежат внутри обёртки `.gai`, поэтому они не трогают разметку Тильды и не ломаются от её CSS.
- Страница разбита на блоки (маркеры `<!-- block:… -->` в `src/index.html`). Каждый блок вставляется в Тильду отдельным блоком T123.
- Шрифты Unbounded и Geologica подключаются с Google Fonts. Общие шрифты сайта в Тильде менять не нужно.
- Главная картинка — скорпион-кресло: по умолчанию сетка в цвете акцента (`hero-art.jpg`), под мышью мелкими пикселями проступает рендер (`hero-render.webp`, грузится только на устройствах с мышью). Обе готовятся из исходной пары скриптом `scripts/prepare-hero.py`.
- Логотип ведёт на https://gripinsky.ru/. Скрипт окна записи встроен в блок с ценами.

На ширине 375, 1440 и 1920 px сборка для Тильды совпадает с оригиналом до пикселя: позиции и высоты всех секций те же.

## Структура

```
src/index.html        лендинг целиком, разбит маркерами на блоки
src/styles.css        стили (всё под .gai)
src/assets/           картинки
tilda.config.json     ссылки на картинки в Тильде, кнопки тарифов, UTM
scripts/build-tilda.mjs  сборка блоков для Тильды
scripts/serve.mjs     локальный просмотр
scripts/prepare-hero.py  подготовка картинок первого экрана (сетка + рендер)
scripts/make-favicon.py  общий фавикон лендинга и сайта (знак в scripts/favicon-mark.path)
brand/favicon/        готовый набор иконок и инструкция по установке
scripts/check-published.mjs  проверка опубликованной страницы
TILDA-TRIAL.md        инструкция пробной публикации
dist/                 результат сборки (не хранится в git)
```

## Команды

Нужен Node.js 20.11 или новее. Внешних зависимостей нет, `npm install` не нужен.

```bash
npm run build   # собрать блоки в dist/tilda/ и предпросмотр dist/tilda-preview.html
npm run dev     # http://localhost:4330/src/ и http://localhost:4330/dist/tilda-preview.html
npm run check -- https://gripinsky.ru/ai-3d-test   # сверить опубликованную страницу с манифестом
```

`dist/tilda-preview.html` показывает блоки в той же обёртке и с тем же глобальным CSS, что и опубликованная страница Тильды.

## tilda.config.json

| Поле | Что вписать |
|---|---|
| `images` | Ссылку на каждую картинку после загрузки в Тильду (`https://static.tildacdn.com/…`). Пока ссылки нет, в блоке стоит заглушка `ЗАГРУЗИТЕ-В-ТИЛЬДУ/…`. |
| `planLinks.self`, `planLinks.support` | Куда ведут кнопки «Выбрать формат». Пусто: открывается окно «Запись пока не открыта». Когда заполнены обе, окно и подпись «Запись пока не открыта» убираются. Варианты: `#order:ИИ в 3D. Самостоятельно=6900` (корзина Тильды, на странице нужен блок корзины ST100), `#popup:…` (попап Тильды) или ссылка на оплату в GetCourse. |
| `modelingCourseUtm` | Метки для ссылок на 1–2 уровень моделирования, например `utm_source=…&utm_medium=…`. Перед заполнением прочитайте примечание в CLAUDE.md. |

После каждого изменения запускайте `npm run build`. Сборка перечисляет, что ещё не заполнено.

## Публикация в Тильде

1. **Картинки.** Загрузите в Тильду файлы из `dist/tilda/upload/`. Например, в любой блок с картинкой на служебной странице: откройте предпросмотр, кликните по картинке правой кнопкой и выберите «Копировать адрес изображения». Ссылки впишите в `images`, затем `npm run build`.
2. **Страница.** В проекте gripinsky.ru создайте пустую страницу. В настройках страницы укажите заголовок и описание из `dist/tilda/page-settings.txt` и адрес страницы, например `ai-3d`.
3. **Блоки.** Добавьте блоки «Другое → T123 (HTML-код)» строго по порядку: `00-styles`, `01-header` … `11-footer`, `12-cookies`. В каждый вставьте содержимое одноимённого файла из `dist/tilda/` целиком. `00-styles` всегда идёт первым.
   - Если на странице будет общая шапка сайта, блок `01-header` не вставляйте. Если общий подвал — то же с `11-footer`.
   - `12-cookies` — плашка согласия на cookie как на новом сайте. Выбор хранится под тем же ключом `gr-cookie-consent`, поэтому после запуска сайта посетителя не спросят второй раз. Если в Тильде включена её собственная плашка cookie, выключите её, чтобы не было двух.
   - Между блоками можно вставлять родные блоки Тильды: отзывы, форму, корзину.
4. **Проверка.** Блоки T123 рисуются только в предпросмотре и на опубликованной странице, в редакторе их может быть не видно. Проверьте:
   - тёмный фон без белых полос между блоками (если полосы есть, поставьте блокам отступы 0);
   - шрифты Unbounded и Geologica в заголовках и тексте;
   - все 6 картинок загрузились (`hero-render.webp` подгружается после загрузки страницы и только на компьютере с мышью);
   - «Посмотреть программу» прокручивает к программе, этапы раскрываются;
   - кнопки тарифов открывают окно или ведут по ссылке из `planLinks`;
   - ссылки на 1–2 уровень открывают https://gripinsky.ru/1-2lvl;
   - мобильная версия (около 375 px).

При правке текста или стилей: меняйте `src/`, запускайте `npm run build` и заменяйте в Тильде содержимое изменившихся блоков.

## Cookie и Яндекс Метрика

Плашка сохраняет выбор посетителя и сообщает о нём событием `gai:cookie-consent` (`detail`: `all` или `necessary`). Тот же выбор доступен в `window.gaiCookieConsent`.

Важно: если Метрика подключена в настройках сайта Тильды, она загружается у всех посетителей, и кнопка «Только необходимые» её не отключает. Чтобы выбор действительно работал, счётчик нужно подключать кодом, который запускается только после события с `all`. Это меняет аналитику всего сайта gripinsky.ru, поэтому решение принимает владелец сайта.
