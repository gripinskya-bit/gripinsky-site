# Пробная публикация лендинга в Тильде

Инструкция для отдельного чата Claude в этой папке. Подготовлено 17.10.2026. Устройство проекта описано в README.md, правила кода в CLAUDE.md.

## Цель

Выложить лендинг «ИИ в 3D» на текущий сайт gripinsky.ru (проект в Тильде) скрытой пробной страницей. Нужно проверить, что блоки T123 в настоящей Тильде выглядят и работают так же, как в `dist/tilda-preview.html`. Это не запуск: страница не попадает в меню и закрыта от индексации.

## Параметры пробной страницы

| Что | Значение |
|---|---|
| Проект в Тильде | gripinsky.ru (действующий сайт) |
| Адрес страницы | `ai-3d-test` (на 17.10 свободен, отдаёт 404). **Не `ai`**: там действующая страница курса по Stable Diffusion. `ai-3d` оставить для боевой версии. |
| Заголовок и описание | из `dist/tilda/page-settings.txt` |
| Индексация | запретить для этой страницы |
| Меню сайта | не добавлять |
| Общие шапка и подвал сайта | не показывать: у лендинга свои блоки `01-header` и `09-footer` |
| Кнопки тарифов | как есть: окно «Запись пока не открыта». `planLinks` не заполнять. |
| UTM | не заполнять (`modelingCourseUtm` пуст, см. CLAUDE.md) |

## Чего не делать

- Не менять настройки всего сайта: шрифты, цвета, аналитику, общие шапку и подвал, плашку cookie Тильды, домен. Если без этого не обойтись, остановиться и спросить пользователя.
- Не трогать и не публиковать другие страницы проекта.
- Не включать корзину и оплату.
- Не вводить логин и пароль Тильды: в аккаунт входит сам пользователь.
- Не править код блоков прямо в Тильде. Правки вносятся в `src/`, затем `npm run build`, затем содержимое блока заменяется целиком.
- Перед нажатием «Опубликовать» показать пользователю, что будет опубликовано и по какому адресу, и дождаться «да».

## Шаги

### 0. Сборка

```bash
npm run build
```

`dist/tilda/manifest.json` содержит порядок блоков, размер каждого в символах (`chars`), список картинок и предупреждения. До загрузки картинок предупреждений об `images` будет пять, это нормально.

### 1. Картинки

1. Загрузить в Тильду 5 файлов из `dist/tilda/upload/`: `hero-art.jpg`, `mesh-scene.jpg`, `mesh-raw.jpg`, `karina-kamola.webp`, `karina-work.jpg`. Например, в блок с картинкой на служебной странице или в Zero Block.
2. Скопировать адрес каждой загруженной картинки (`https://static.tildacdn.com/…`) и вписать в `images` в `tilda.config.json`.
3. Если Тильда не принимает `.webp`, перевести в jpg и поправить `src="assets/karina-kamola.webp"` в `src/index.html` и ключ в конфиге:
   ```bash
   sips -s format jpeg src/assets/karina-kamola.webp --out src/assets/karina-kamola.jpg
   ```
4. Выполнить `npm run build`: предупреждений об `images` быть не должно.
5. Служебные блоки с картинками после этого удалить, если они были только для загрузки.

### 2. Страница

Создать пустую страницу в проекте gripinsky.ru с параметрами из таблицы выше.

### 3. Блоки

Добавить блоки «Другое → T123 (HTML-код)» строго в порядке `manifest.json`:

`00-styles` → `01-header` → `02-hero` → `03-pains` → `04-program` → `05-result` → `06-teacher` → `07-pricing` → `08-faq` → `09-footer` → `10-cookies`

- В каждый блок вставить содержимое `dist/tilda/NN-name.html` целиком, без правок.
- Самые большие блоки: `09-footer` (около 48 тыс. символов, внутри SVG-логотип), `00-styles` (около 24 тыс.) и `04-program` (около 22 тыс.). Через браузер их надёжнее вставлять из буфера или через API редактора кода, а не печатью по символу. После вставки сверить длину с `chars` в манифесте.
- Если Тильда не принимает блок такого размера: для `09-footer` загрузить логотип отдельной картинкой (SVG лежит в `src/index.html`, тег `svg.footer-logo`) и заменить его на `<img>`. Об этом сообщить пользователю.
- Отступы сверху и снизу у блоков T123 должны быть 0.

### 4. Предпросмотр и публикация

1. Открыть предпросмотр страницы. В редакторе блоки T123 могут не отображаться, это нормально.
2. Если в предпросмотре всё в порядке, спросить пользователя и после «да» опубликовать.

### 5. Проверка опубликованной страницы

```bash
npm run check -- https://gripinsky.ru/ai-3d-test
```

Скрипт сверяет страницу с манифестом: все 10 блоков с разметкой на месте и по порядку, есть CSS и шрифты, нет заглушек `ЗАГРУЗИТЕ-В-ТИЛЬДУ`, все картинки открываются, есть плашка cookie и окно записи, и показывает meta robots. Должно завершиться строкой «Всё на месте.».

Затем проверить в браузере на 1440 px и 375 px, сверяясь с `npm run dev` → `http://localhost:4330/dist/tilda-preview.html`:

- [ ] фон тёмный по всей странице, без белых полос между блоками;
- [ ] заголовки набраны Unbounded, текст Geologica;
- [ ] в первом экране полосу «модель / в окружении» можно тянуть мышью и пальцем, при появлении она один раз качнётся;
- [ ] «Посмотреть программу» прокручивает к программе (Тильда может перехватывать якорные ссылки, проверить отдельно), этапы раскрываются;
- [ ] «Освоить пайплайн» (под программой) и «Выбрать формат» (в блоке результата) прокручивают к ценам;
- [ ] кнопки тарифов открывают окно с названием тарифа, окно закрывается крестиком и кликом по фону;
- [ ] вопросы в FAQ раскрываются;
- [ ] в подвале открываются ссылки на оферту, политику, согласие, Telegram и почту;
- [ ] плашка cookie появляется при первом визите, после выбора исчезает и при перезагрузке больше не появляется (для повторной проверки очистить `localStorage` ключа `gr-cookie-consent`);
- [ ] нет второй плашки cookie от Тильды;
- [ ] нет горизонтальной прокрутки на 375 px;
- [ ] в консоли нет ошибок от кода лендинга.

### 6. Отчёт

Пользователю сообщить адрес страницы, вывод `npm run check`, результаты чек-листа (по скриншоту десктопа и мобильного) и всё, что пришлось сделать иначе, чем здесь написано. Заполнить журнал ниже.

## Известные риски

- **Якоря.** Тильда может обрабатывать ссылки `#program` и `#pricing` своим скриптом. Если прокрутка не работает, не чинить в Тильде, а сообщить.
- **Метрика.** Если она подключена в настройках сайта, то загружается у всех посетителей, кнопка «Только необходимые» её не отключает (см. README, раздел «Cookie и Яндекс Метрика»). Для пробной страницы ничего не менять, просто отметить в отчёте.
- **Google Fonts.** Шрифты грузятся с fonts.googleapis.com. Если они не подгрузились, это видно по заголовкам: вместо Unbounded будет системный шрифт.
